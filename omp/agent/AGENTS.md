# 言語

- ユーザーとの会話および回答には、原則として日本語を使用する。

# コミットメッセージ

- 別途CHANGELOGは作らず、コミットログを変更履歴として扱う。`git log` だけで何が変わったか追えるように書く。
- 件名は Conventional Commits（`feat(scope): …`、`fix`、`chore`、`docs`、`style`、`refactor`）で、変更内容を一行で要約する。
- 変更が複数あるときは、本文に箇条書きで対象（ファイルや設定キー）と変更内容を書く。理由が自明でなければ一言添える。
- 無関係な変更は一つのコミットに混ぜず、分けてコミットする。
